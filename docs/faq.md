# 常见问题

## 要同时开 Clash 和独立 Tailscale 吗？

最终方案不需要。Windows 上的 Tailscale 连接由 Mihomo 内置组件建立，日常只需 Clash。独立客户端可作初次准备和应急通道；服务器仍运行 Tailscale 与 Xray 两个服务。

## 有完全免费的版本吗？

软件组件可用开源版本，服务器、带宽和组网服务有各自成本与使用条件。已有服务器的读者不一定需要增加付费代理服务；额度和费用以提供商当前规则为准。

## 免费流量多少 GB？带宽多少 Mbps？

截至 2026-10-26，官方价格页未为普通 tailnet 组网列出固定的月度 GB 数据包，也未承诺所有连接统一的免费 Mbps。直连主要受两端线路与设备限制；DERP 中继有公平使用的吞吐限制，不等于不限速公共中转。

Personal 当前为个人非商业用途的免费套餐，列有 6 位用户、不限 user devices 等资源规则；服务器和手机热点流量仍由各自提供商计算。详见 [完整解释与官方来源](tailscale-network-and-cost.md)。

## 本机公网 IP 经常变化怎么办？

节点配置不绑定本机公网 IP。切换 Wi-Fi、热点或运营商后会重建连接，仍可能短暂断流。如果服务器被删除后注册成新设备，应重新核对它的 tailnet 地址。

## 本地连不上服务器公网 IP，也能用吗？

可能有帮助，但前提是本地网络可接入 Tailscale，服务器仍可联网并加入同一个 tailnet。拥有账号并不保证任意网络限制下都可达。

## 为什么不只换域名？

域名通常仍解析到服务器 IP。如果受影响的是该 IP 的网络路径，换名字并不改变连接路径。先区分 DNS 问题与网络路径问题。

## Cloudflare Tunnel 能直接替代吗？

网站发布、私网访问和通用代理出口是不同用途。一个 HTTP 隧道地址不等于可以直接填进 Clash 的 VLESS/SOCKS 节点。使用其它隧道需要重新确认协议和客户端要求；本教程只实现图示中的 Tailscale 方案。

## 为什么代理页面只显示 SERVER？

这是正常设计。`SERVER` 是选择组，`SERVER-NODE` 是它使用的节点；`TAILNET` 是内部通道，不是要手动轮换的另一个出口。页面完全空白时见 [故障排查](troubleshooting.md)。

## 开了 Clash，浏览器为什么还走本地？

检查【系统代理】或【TUN】是否开启。只启动界面不等于接管流量。测试脚本显式使用本地代理，可帮助区分“代理本身不通”和“软件未使用代理”。

## 国内个别站点也走了代理？

域名集合、GeoIP 与 CDN 位置可能和需求不一致。先看【连接】中命中的规则，再把目标域名的直连规则放到最后的 `MATCH,SERVER` 前面。一个站点也可能同时请求多个地区的域名。

## 服务器要开放什么端口？

VLESS 入口是 tailnet 地址上的 TCP `10808`，不是公网 `10808`。Tailnet ACL/grants 应允许指定客户端访问。Tailscale 自身直连/中继需要的网络条件属于另一层，按其官方文档检查。

## 手机可以照抄吗？

可执行流程面向 Windows。移动系统的 VPN 接管、客户端内核、Tailscale 支持与后台限制可能不同，应另选并验证对应客户端。

## 我只想全部流量走服务器，需要这么复杂吗？

不一定。简单全局出口可先了解 Tailscale exit node，见 [可选全局出口](deployment.md#附录-b可选的全局出口通道)。

## 怎么停用？

先关系统代理和 TUN。服务器代理可用 rollback 脚本停用，Clash 可从事先备份恢复，见 [回退与恢复](deployment.md#7-回退与恢复)。
